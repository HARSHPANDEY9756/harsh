# StockScope

A lightweight stock analysis website that provides quick recommendations based on key metrics.

## Features

- Select from sample stocks and instantly view:
  - Price
  - P/E ratio
  - Revenue growth
  - Debt-to-equity
  - ROE
- Get a recommendation badge: **Buy / Hold / Sell**
- Enter custom metrics to evaluate any stock profile
- Fully static (no build step required)

## Run locally

Open `index.html` directly in a browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit: <http://localhost:8000>
